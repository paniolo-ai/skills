# Audience and Tone

Assume the reader is a competent developer but may be new to this project.

**✅ Good tone:**

```markdown
Use `vi.mocked()` to cast mocked functions with proper types.
```

**❌ Avoid:** Condescending tone (`"Obviously..."`) or over-explaining basics that TypeScript
developers already know.
